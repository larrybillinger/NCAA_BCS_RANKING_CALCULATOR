# v0.5.1 — Deployment version visibility and model sync

Released 2026-09-17.

## Problem fixed

The Synology updater correctly downloaded new GitHub source but preserved the existing `/volume1/rankings/.env` file unchanged. That also preserved `MODEL_VERSION=division_i_weighted_v1`, so the website continued selecting the old v1 Week 2 snapshot after v0.5.0 code and recalculated CSVs had been committed.

## Fix

The standard GitHub-backed Synology updater now reads the committed non-secret model identifiers from `.env.example` and updates only:

```text
MODEL_VERSION
PREDICTOR_VERSION
```

Database passwords, CFBD keys, ports, and other NAS-specific settings remain preserved.

## Visible deployment identity

The Weekbook sidebar now displays:

```text
App v0.5.1
Model division_i_weighted_v2
Predictor rank_gap_v2
```

The `/health` endpoint reports the same values.
