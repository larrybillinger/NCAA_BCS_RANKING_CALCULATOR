# v0.8.0 — Bye-week-neutral average ranking score

Released 2026-09-18.

## Why

Cumulative ranking points rewarded teams simply for playing more games. A team with three completed games had three opportunities to accumulate game points while a team with two games had only two, even if the two-game team had performed better on a per-game basis.

## New ranking value

Every game still earns and freezes its normal production game score.

```text
Ranking Score = Sum of Frozen Game Scores / Games Played
```

A bye week therefore changes neither numerator nor denominator.

## Audit values

PostgreSQL keeps:
- `score`: ranking average used for ordering;
- `raw_score`: cumulative frozen game-score total;
- `games_played`: denominator used to calculate the average.

## Tie-breakers

Exact average-score ties use:
1. head-to-head;
2. win percentage;
3. average opponent strength per game;
4. deterministic name fallback.
