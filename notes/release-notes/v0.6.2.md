# v0.6.2 — Retrocast route compatibility

Released 2026-09-18.

## Problem

The homepage loaded, but pages that consumed research retrocasts returned HTTP 500. The in-memory retrocast object used `home_points`, `away_points`, and `margin`, while the existing templates and accuracy code expected the persisted prediction field names `projected_home_points`, `projected_away_points`, and `projected_margin`.

## Fix

Research retrocasts now expose the same projected-score and margin interface as persisted predictions. Team pages, historical Game Book pages, and Accuracy can therefore use either object without branching.

Expected health after deployment:

```text
app_version: 0.6.2
model_version: division_i_weighted_v3
predictor_version: rank_gap_v3
```
