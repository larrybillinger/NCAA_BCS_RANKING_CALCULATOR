# v0.6.1 — Reliable Synology deployment

Released 2026-09-18.

## Problem

A Synology update successfully downloaded v0.6.0 and finished exporting the new web/worker images, but Docker Compose returned `DeadlineExceeded` before it recreated the running containers. The old v0.5.2 containers therefore remained live even though newer images existed.

## Fix

- Build a single `ncaa-rankings-app:latest` image once.
- Use that image for both web and worker.
- Keep PostgreSQL running independently.
- Force-recreate only the web and worker containers after the image build.
- Extend Docker/Compose client timeout values to 1200 seconds.
- Wait for the health endpoint.
- Verify that `app_version`, `model_version`, and `predictor_version` exactly match GitHub before the updater reports success.

Expected healthy release:

```text
app_version: 0.6.1
model_version: division_i_weighted_v3
predictor_version: rank_gap_v3
```
