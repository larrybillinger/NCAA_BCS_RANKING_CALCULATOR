# Release v0.4.0

## Summary
Adds the production D1 Rank Weekbook website, PostgreSQL persistence, automatic college-football data ingestion, locked predictions, model statistics, and Synology deployment.

## Changes
- Weekbook ranking UI and persistent week spine.
- Game Book with future/past week navigation.
- Team schedule/projection pages.
- Model accuracy dashboard.
- CFBD worker and PostgreSQL schema.
- Synology installer, updater, and backup scripts.
- Final 2026 Week 2 official ranking included.

## Fixed bugs
- No prior website release existed.

## Known issues
- Official prediction statistics begin after deployment because past predictions are not fabricated retroactively.
- Provider schedule corrections may require an operational override in a later release.

## Upgrade steps
Run `scripts/synology-update.sh` on an existing installation, or `scripts/synology-install.sh` for a new installation.

## Rollback notes
Application code backups are created under `/volume1/rankings/backups`. PostgreSQL should be backed up with `scripts/synology-backup.sh` before major future upgrades.
