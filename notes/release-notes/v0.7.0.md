# v0.7.0 — Margin-and-site production scoring

Released 2026-09-18.

## Production formula

For an opponent ranked `R` in a pool of `N` teams:

```text
Home or neutral win = (N + 1 - R) + scoring margin
Away win            = (N + 1 - R) + scoring margin + 7

Away or neutral loss = (-R) + scoring margin
Home loss            = (-R) + scoring margin - 7
```

There is no separate +10 for winning.

## Division I percentages

```text
FBS vs FBS       = 100%
FBS vs FCS       = 100%
FCS vs FCS       = 50%
FCS loss to FBS  = 50%
FCS win over FBS = 100%
```

FCS is Division I. The separate FBS/FCS labels exist only to make the production scaling explicit. The percentage scales opponent-rank and margin points; the ±7 site adjustment is then applied at full value.

## Audit

A new `site_points` field records the +7 / -7 adjustment in PostgreSQL ranking-game audits.

## Snapshot safety

The archived Week 1/2 CSVs remain v3 artifacts. The v4 worker rebuilds completed weeks from the synced CFBD/PostgreSQL game data so previous formula results are never mislabeled as v4.
