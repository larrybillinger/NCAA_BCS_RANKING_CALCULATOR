# v0.11.0 — Official hybrid prediction

## Summary

`hybrid_core_v1` is now the official D1 Rank score/winner predictor. The national ranking remains `division_i_weighted_v5` with no ranking-formula changes.

## Official predictor

The hybrid prediction combines:

- 40% calibrated rank-gap margin;
- 60% current-season offense/defense matchup margin;
- offense/defense profiles shrunk toward the Division I scoring mean with three pseudo-games.

Because the offense/defense signal can outweigh the rank-gap component, the official predictor may select a lower-ranked team to win. That changes predictions only; it does not change the ranking order or ranking points.

## Site-wide promotion

- Game Book current and future projections use `hybrid_core_v1`.
- Team schedule projections use `hybrid_core_v1`.
- Official Accuracy metrics filter to locked `hybrid_core_v1` predictions.
- Historical Accuracy retrocasts run the hybrid using only information available before each game.
- Team accuracy/retrocast sections use the hybrid.
- The old anonymous rank-only calculator is replaced by a team-vs-team matchup calculator so the offense/defense signal is not discarded.
- Sidebar, footer, Method Notes, health/version reporting, and documentation identify `hybrid_core_v1` as the active predictor.

## History remains immutable

Previously locked `rank_gap_v3` official predictions remain in PostgreSQL exactly as they were. They are retired from the active hybrid ledger and are not rewritten as hybrid predictions.

The three (or other existing) pre-promotion `hybrid_core_v1` shadow rows remain in the research ledger for audit. The worker stops creating a duplicate shadow copy of the base hybrid model after promotion because the same model is now official.

## Research boundary

Home-field, stadium-demand, travel, time-zone, altitude, weather, and other context adjustments remain research-only. v0.11.0 promotes only the validated base `hybrid_core_v1` blend.

## Deployment

The normal Synology updater synchronizes `PREDICTOR_VERSION=hybrid_core_v1` from `.env.example`, preserves secrets, recreates web/worker, and verifies `/health` reports the expected app/model/predictor versions.

After deployment verify:

1. `/health` reports app `0.11.0`, model `division_i_weighted_v5`, predictor `hybrid_core_v1`.
2. Game Book future games show current hybrid projections.
3. Accuracy labels the official hybrid ledger and hybrid historical retrocast.
4. New hybrid predictions lock at kickoff.
5. Previously locked `rank_gap_v3` rows remain historical and unchanged.
