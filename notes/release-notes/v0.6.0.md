# v0.6.0 — First-game baseline and Weekbook completion

Released 2026-09-17.

## Ranking behavior

Every Division I team starts from the same neutral T-1 state. In a 266-team pool the opponent-scoring value of that state is 133.5.

A team stays at that neutral scoring value until it completes its first current-season game. Once it has a result, future games use its immediately preceding completed-week scoring rank.

Provider Week 0 is normalized into ranking Week 1.

The live model identifiers are:

```text
MODEL_VERSION=division_i_weighted_v3
PREDICTOR_VERSION=rank_gap_v3
```

The current 2026 Week 1 and Week 2 Kansas State/Tulane sanity check remains:

```text
Kansas State  #40   2-0   298.5
Tulane       #105   1-1    72.0
```

## Weekbook clarity

Projected scores now name the team beside its projected points. Team pages and Game Book explicitly identify the projected winner and win chance rather than showing an unlabeled score pair.

Rank history starts with:

```text
Season start   T-1   neutral scoring rank 133.5
After Week 1   #...
After Week 2   #...
```

## Historical model checks

Games that occurred before the installed site had locked predictions can now show a RESEARCH RETROCAST. The retrocast is rebuilt only from the ranking available before that game.

Retrocasts:
- never overwrite an official prediction;
- never count toward official accuracy;
- populate a separate research accuracy section;
- can be shown on team pages and completed Game Book weeks.

## Deployment

The normal Synology updater pulls this release from GitHub and synchronizes the committed non-secret model/predictor identifiers while preserving the CFBD key and database credentials.
