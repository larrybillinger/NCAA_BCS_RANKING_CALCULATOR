# v0.10.1 — Site cleanup

Released 2026-10-06.

This is a website cleanup and reliability release. The ranking formula remains
`division_i_weighted_v5` and the official predictor remains `rank_gap_v3`.

## Ranking page

The default view now shows only the national rank. Scope ranks appear only when a
scope is selected:

```text
All teams:    Rank | Team | Div. | Record | Avg score | Move
FBS or FCS:   FBS rank | D-I | Team | Record | Avg score | Move
Conference:   Conf. rank | FBS | D-I | Team | Record | Avg score | Move
```

Scope ranks are still derived from the single national Division I order.

## Accuracy page

The Accuracy page was recalibrating the predictor from scratch for every
completed game it evaluated, so it slowed down every week and eventually timed
out. Calibration, ranking lookups, and hybrid scoring profiles are now cached for
the duration of a request and dropped on every commit, so the worker never
reuses a value computed before it wrote new data. The worker's prediction
generation benefits from the same cache.

## Official ledger

The official accuracy numbers previously counted any locked `rank_gap_v3`
prediction, including those built from retired ranking models (`v1`–`v4`) that
remain in the database from mid-September. They now count only predictions built
from the active `MODEL_VERSION`. Older rows are kept, not deleted or rewritten.

Kickoff locking applies the same rule: the active model's latest prediction
created before kickoff is locked even if a retired model's row was locked
earlier. Nothing created after kickoff can be locked.

After deployment, the footer ticker and Accuracy page may show different
official numbers than before because retired-model games are no longer mixed in.

## Other cleanup

- Game Book times use the configured local timezone.
- Unplayed games show UPCOMING or IN PROGRESS.
- The rank calculator's neutral-site checkbox was removed because it never changed the projection.
- The Game Book mobile layout is no longer overridden by a tablet rule.
