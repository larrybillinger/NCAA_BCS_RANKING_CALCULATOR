# v0.11.2 — Full Markdown prediction diagnostics

## Purpose

v0.11.2 adds observability around the production prediction method so the live hybrid can be analyzed game by game rather than judged only from headline accuracy percentages.

The production ranking and prediction formulas do not change in this release.

## Accuracy export

The Accuracy page now includes:

```text
Export full diagnostics (.md) ↓
```

The download route is:

```text
/stats/export.md
```

The generated file is named:

```text
d1-rank-2026-prediction-diagnostics.md
```

The export is generated from the current PostgreSQL data and model code when requested. It is read-only and does not write or rewrite rankings, predictions, or results.

## Export contents

The Markdown file includes:

- application, ranking-model, and predictor versions;
- exact active hybrid weights and shrinkage constants;
- rank-slope fallback, bounds, and margin cap;
- completed-game coverage for every week, including Week 1;
- source-week ranking snapshot/calibration state;
- source-week offense/defense scoring-profile state;
- official locked hybrid metrics;
- leakage-safe historical retrocast metrics;
- archived pre-promotion hybrid shadow metrics;
- week-by-week metrics for each separate sample;
- an explicit Weeks 3–5 reproduction slice for comparison with the earlier hybrid research;
- one row per historical retrocast game with the intermediate calculations that produced the prediction;
- official locked prediction rows with their stored model-detail values;
- archived shadow rows with their stored model-detail values.

## Per-game diagnostics

For leakage-safe retrocasts the export includes, where available:

- prior ranking week;
- home and away ranks;
- rank gap;
- calibrated rank slope;
- raw rank-margin component;
- weighted rank contribution;
- home/away offense and defense profiles;
- number of prior games in each team's scoring profile;
- home and away matchup bases;
- offense/defense margin;
- weighted offense/defense contribution;
- continuous projected scores and margin;
- winner-consistent display scores;
- home win probability;
- actual score and margin;
- winner correctness;
- margin absolute error;
- score MAE;
- total-score absolute error;
- per-game Brier error;
- whether independent integer rounding would have produced a false displayed tie.

New predictions also retain richer `model_detail` values for future audits. These additions are diagnostic metadata only; they do not alter the projection.

## Reproducibility workflow

The export deliberately separates:

```text
Official locked predictions
Historical leakage-safe retrocasts
Pre-promotion locked shadow predictions
```

The Weeks 3–5 retrocast slice is called out separately so its exact game count and metrics can be compared with the earlier research sample before changing the production model. If the samples or intermediate calculations differ, the difference should be identified before tuning weights or shrinkage.

## Security

The public export contains derived model diagnostics and ordinary game facts only. It does not include:

- CFBD API keys;
- PostgreSQL credentials;
- admin credentials;
- `.env` contents;
- raw CFBD payloads.

## After deployment

1. Confirm `/health` reports the versions above.
2. Open Accuracy.
3. Click **Export full diagnostics (.md) ↓**.
4. Save the generated Markdown file.
5. Compare the Weeks 3–5 reproduction slice and per-game calculations with the earlier research before making any predictor changes.
